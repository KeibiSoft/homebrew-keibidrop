# Homebrew Tap for KeibiDrop

End-to-end encrypted peer-to-peer file sharing.

## Install

```bash
brew tap KeibiSoft/keibidrop
brew install keibidrop
```

## Usage

```bash
keibidrop          # Desktop UI
kd start           # CLI daemon
keibidrop-cli      # Interactive REPL
```
